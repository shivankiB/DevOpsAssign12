This project demonstrates a complete CI/CD pipeline for deploying a Django web application using:

Terraform – to provision AWS infrastructure
Ansible – to configure instances and set up Docker Swarm
Docker & Docker Swarm – to containerize and orchestrate the Django ap
Jenkins – to automate the CI/CD pipeline
PostgreSQL – as the backend database for the Django app
The entire workflow is automated — from infrastructure creation to app deployment.
